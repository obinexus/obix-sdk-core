# Changelog — obix-sdk-core

The history of `obix-sdk-core`. The lineage in full is `PROVENANCE.json`, in this package and in its repository ([https://github.com/obinexus/obix-sdk-core](https://github.com/obinexus/obix-sdk-core)).

## 0.5.0

- Named `obix-sdk-core` without an npm scope (the owner's decision D-102, 2026-09-29). Previous name: `@obinexusltd/obix-sdk-core`. The package, its version and its exports did not change with the name.
- Repository, issues and homepage: [github.com/obinexus/obix-sdk-core](https://github.com/obinexus/obix-sdk-core); the repository starts from a clean export of the OBIX monorepo (its commit is recorded in the repository's copy of PROVENANCE.json).
- A compatibility package: every export is the export of [`obix-core-runtime`](https://github.com/obinexus/obix-core-runtime) under the old name (SDK core import path for ObixRuntime (the repository is empty; the docs import it)).
